# IranianChat API

NestJS backend boundary for identity, tenants, messaging, organizations, files, notifications, moderation and security.

## Module boundaries

- `identity`
- `tenants`
- `users`
- `organizations`
- `conversations`
- `messages`
- `groups`
- `channels`
- `files`
- `notifications`
- `presence`
- `search`
- `moderation`
- `audit`
- `security`

The first implementation milestone will add the NestJS bootstrap and health endpoint, then identity and tenant isolation before messaging features.
